# قصر الزهور

[تنزيل قصر الزهور لويندوز 64 بت](https://github.com/otakuiv3/Qasr-AlZuhur/releases/latest/download/Qasr-AlZuhur-Windows-x64.zip)

فك الضغط بالكامل داخل مجلد يمكنك الكتابة فيه، ثم افتح **lichii.exe** الموجود داخل المجلد مباشرة. تظهر هوية قصر الزهور داخل المحاكي.

عند توفر تحديث يعرضه المحاكي عند التشغيل وفق إعداداتك. اضغط **Install** لتنزيل التحديث وتثبيته.
